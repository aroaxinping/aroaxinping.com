# aroaxinping.com

Blog personal de Data Science en espanol. Tutoriales de Python, SQL, Pandas, EDA y visualizacion de datos para principiantes.

## Sobre el proyecto

Web estatica hecha con HTML, CSS y JavaScript vanilla. Sin frameworks, sin build tools. Alojada en GitHub Pages.

**Live:** [aroaxinping.com](https://aroaxinping.com)

## Estructura

```
.

├── roadmap.html            # Mi ruta de aprendizaje en Data Science

├── blog/                   # Articulos del blog
```

## Features

- **Dark mode** con toggle y deteccion de preferencia del sistema
- **Terminal interactiva** en la homepage (escribe `help` para ver los comandos)
- **MP3 player retro** con playlist simulada
- **Blog con SEO** — meta tags, Open Graph, canonical URLs, JSON-LD schema, hreflang
- **Auto-generado en blog posts** — tabla de contenidos, breadcrumbs, tiempo de lectura, botones de compartir
- **Filtros** por categoria en blog y portfolio
- **Scroll reveal** animations
- **Responsive** — mobile first, breakpoint a 768px
- **Easter egg** — Konami code ;)

## Stack

- HTML5 + CSS3 (custom properties, grid, flexbox)
- JavaScript vanilla (ES6+)
- Google Fonts: Sora, DM Sans, JetBrains Mono, Press Start 2P
- GitHub Pages para hosting

## Desarrollo local

```bash
python3 -m http.server 3000
```

Abrir `http://localhost:3000`
